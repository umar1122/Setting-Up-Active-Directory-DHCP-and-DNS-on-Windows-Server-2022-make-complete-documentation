# Windows Server Installation

## Goal

Install Windows Server 2022 in a virtual machine and prepare it for the home lab.

## Requirements

- Windows Server 2022 ISO
- VirtualBox or VMware
- At least 4 GB RAM
- 2 CPU cores
- 60 GB virtual disk
- Network adapter configured for the lab

## Step 1: Create the virtual machine

Create a new virtual machine and select the Windows Server 2022 ISO.
