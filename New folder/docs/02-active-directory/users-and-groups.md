# Active Directory Users and Groups

## Goal

Create test users and security groups for the lab.

## Step 1: Open Active Directory Users and Computers

Open:

**Server Manager → Tools → Active Directory Users and Computers**

**Screenshot:**  
`![AD Users and Computers](../screenshots/15-ad-users-computers.png)`

## Step 2: Create a security group

Create a group such as:

`IT-Users`

Choose the appropriate group scope and security type for the lab.

**Screenshot:**  
`![Create group](../screenshots/16-create-group.png)`

## Step 3: Create a test user

Create a non-production test account such as:

`test.user`

Use a strong lab password.

**Screenshot:**  
`![Create user](../screenshots/17-create-user.png)`

## Step 4: Add the user to the group

Open the user's properties and add the account to the appropriate group.

**Screenshot:**  
`![Group membership](../screenshots/18-group-membership.png)`
