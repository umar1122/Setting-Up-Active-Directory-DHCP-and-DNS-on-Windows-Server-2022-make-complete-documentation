# Wireshark Packet Captures

## Goal

Capture and inspect traffic generated by the lab.

## Step 1: Select the network interface

Open Wireshark and select the interface connected to the lab network.

**Screenshot:**  
`![Wireshark interface](../screenshots/36-wireshark-interface.png)`

## Step 2: Start a capture

Start the capture and generate normal lab traffic.

**Screenshot:**  
`![Packet capture](../screenshots/37-packet-capture.png)`

## Step 3: Stop and save

Stop the capture and save it as a `.pcapng` file.

Keep captures containing sensitive information inside the private lab.
