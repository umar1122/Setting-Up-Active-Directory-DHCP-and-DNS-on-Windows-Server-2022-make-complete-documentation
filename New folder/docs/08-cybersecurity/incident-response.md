# Incident Response

## Basic lab workflow

When investigating a suspected incident:

1. Identify the event.
2. Record the time and affected system.
3. Preserve relevant logs.
4. Determine the scope.
5. Contain the affected system when appropriate.
6. Investigate the cause.
7. Remove the cause.
8. Recover the system.
9. Document lessons learned.

## Documentation

For each incident record:

- Date and time
- Affected host
- Observed indicators
- Evidence collected
- Actions taken
- Final result
- Lessons learned
