# Security Basics

## Lab security principles

This lab is intended for learning and testing in an isolated environment.

Important principles:

- Use test accounts instead of personal accounts.
- Do not expose lab services directly to the internet.
- Keep operating systems patched.
- Use strong passwords.
- Apply least privilege.
- Enable logging and monitoring.
- Document configuration changes.
