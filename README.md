Windows Server 2022 Home Lab: Active Directory, DHCP & DNS
Overview

This project documents my hands-on home lab experience with Windows Server 2022. The lab focuses on deploying and configuring core Windows network services, including Active Directory Domain Services (AD DS), DNS, and DHCP.

The goal of this project was to build a practical Windows domain environment and gain experience with server administration, network services, user and group management, domain authentication, and troubleshooting.

What I Learned
Installing and configuring Windows Server 2022
Installing and configuring Active Directory Domain Services (AD DS)
Creating and managing an Active Directory domain
Creating users, groups, and Organizational Units (OUs)
Understanding the role of DNS in an Active Directory environment
Installing and configuring DNS
Installing and configuring DHCP
Creating DHCP scopes and configuring IP address distribution
Joining Windows client machines to an Active Directory domain
Testing domain authentication and network connectivity
Troubleshooting common DNS, DHCP, and domain connectivity issues
Understanding how Active Directory, DNS, and DHCP work together
Performing basic Windows Server administration
